## [1.0.0] — 2025-12-18

### Added
- Initial release of the Regex Concatenation Tool
- URL input textarea accepting one URL per line
- Five URL clean-up options: keep full URL, remove scheme, remove scheme + subdomain, remove scheme/subdomain/domain, remove scheme/subdomain/domain/leading slash
- Two regex matching modes: strict (appends `$`) and wildcard (appends `.*`)
- Live processing — output regenerates on every input change
- Auto-copy output to clipboard via browser Clipboard API
- Siege Media brand styling (black background, red accents)
